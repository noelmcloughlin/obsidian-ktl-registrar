# Left out on purpose

- The other modules in `src/` implement features the Service concepts describe at command level, for example `propose.ts` behind *Promote body links*, `public-api.ts` behind the read-only `api`, and `scaffold-modal.ts` behind the header command's two-choice modal.

- `.assets/*.svg` holds the logo and the pictures in `docs/architecture.md`, which carry no claim of their own.

- Repository plumbing with no claim of its own: `community-plugin-entry.json`, `NOTICE`, `LICENSE`, `lychee.toml`, `.editorconfig`, `esbuild.config.mjs`, `tsconfig.json`, `version-bump.mjs`, `versions.json`, `obsidian.code-workspace`, `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md`, `.github/scripts/changelog-release.mjs` (described in `playbooks/releasing.md`), `scripts/build-vocab.mjs`, `scripts/fixtures/`, `.gitignore`, `.npmrc`, `package-lock.json` and `styles.css`. `src/lokf-vocab.json` is generated by `npm run build-vocab`, which `playbooks/contributing.md` describes.

- The rest of `website/` (`astro.config.mjs`, `package.json`, `package-lock.json`, `tsconfig.json`, `NOTICE`, `.gitignore`, `scripts/` and `src/`), the site's build code and house style, which `website/README.md` describes and `playbooks/knowledge-website.md` covers.

- The sidecar's own tooling under `.lokf/` (`scripts/`, `m365/`, `README.md`, `queries.http`), which are copies of the `ktl-sidecar` templates.

- `CHANGELOG.md`, the release history, read when a concept needs a date.

# Gaps

- `.github/workflows/knowledge-release.yaml` has no concept. `SECURITY.md` lists it as the template's jobs, inert until dispatched or turned on by `KNOWLEDGE_RELEASE_ENABLED`, with `attach` the only job that can write.

- `llms.txt`, the agent context file, has no concept.

- `.github/workflows/knowledge-sync.yaml` and its pull request template, `.github/PULL_REQUEST_TEMPLATE/knowledge-sync.md`, have no concept. The workflow's header says it keeps the sidecar's copies and the skills pin at the newest release of Knowledge Trust Ladder each week, and opens one pull request with the `KNOWLEDGE_SYNC_TOKEN` secret. `SECURITY.md` does not list it yet.
