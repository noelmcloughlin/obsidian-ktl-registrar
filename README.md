# KTL Registrar

> "We lasso the world with networks of silver-coloured Italian hemp,\
> We bind down the world into some sort of order;\
> We balance the earth in a pair of scales of our own devising."\
> — Amy Lowell, *The Congressional Library* (1922)

This Obsidian plugin keeps a **LOKF knowledge bundle** well-formed as you edit it. Open the bundle as an Obsidian vault. A status-bar icon says where things stand, the offending frontmatter is underlined as you type, and a side panel names each finding in plain words. It needs no configuration, no network and no servers.

To install, see [the quick start](https://w3id.org/ktl/registrar/docs/install/#quick-start). [The architecture](https://w3id.org/ktl/registrar/docs/architecture/) says what a bundle is, which role this plugin plays in keeping one, and how it sits beside your own notes. [Using it](https://w3id.org/ktl/registrar/docs/using/) lists the report panel, the in-editor diagnostics, the commands, the settings and the read-only API for other plugins.

> **Only want to ask?** Install `ktl-docent` into any agent you use, by a route from [the install page](https://w3id.org/ktl/docs/install/), and ask it about this project. It answers from the bundle and says how far each answer has been checked.
>
> **Agents:** if `.lokf/knowledge/index.md` exists, read it first. `llms.txt` says how to weigh it.

KTL Registrar is the **registrar** of [Knowledge Trust Ladder](https://w3id.org/ktl/) (KTL): it checks that every record is well-formed. Its sibling [KTL Curator](https://w3id.org/ktl/curator/) records what a person decides about each record. Neither reaches a verdict of its own. The judging stays with the person.
